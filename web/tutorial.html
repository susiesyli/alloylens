AlloyLens Walkthrough

A brief step-by-step guide to get started with the webapp.

Step 1 — Choose Features

On the left under Select features, pick which variable groups to show (Inputs, Elements, Microstructures, Properties). Use the checkboxes to filter lists.

Tip: Use Select all or Clear for each axis panel to quickly modify selections.

Step 2 — Configure Axes

Choose X-axis (columns) and Y-axis (rows) variables from the lists. The SPLOM (scatterplot matrix) will be built from these selections.

Step 3 — Apply & View

Once features are selected, return to the main area and click the button labeled Apply (if present) or wait for the plots to render. The plot area shows a summary and the SPLOM.

Step 4 — Export Results

Use the Export selected button in the controls to download the currently selected items.

Step 5 — Surrogate Model

Toggle Show surrogate curves to overlay predicted curves from the surrogate model. This helps compare experimental data to model outputs.

Note: Surrogate model behavior depends on the chosen features.

Step 6 — Recommendation Range

Adjust the Distance threshold slider to control the recommendation neighborhood size. The displayed value shows the current threshold.

Helpful Hints

  • Start with a small set of features to quickly inspect trends.
  • Use the selected count to know how many items are active.
  • Check the console for errors if plots fail to render.
