How to use AlloyLens

Find alloys that meet a design target by filtering their compositions and properties.

  1. Choose features

    In panel a, tick the groups to list (inputs, elements, microstructures, or properties), then pick variables for the X axis and Y axis. The scatterplot matrix updates as you choose.

  2. Set target ranges

    In panel b, drag the sliders along each axis, or draw a box on any plot. Alloys inside every range turn magenta. Double-click a slider to reset it.

  3. Review recommendations

    If no alloy fits your ranges, the closest ones are recommended in yellow. Use the recommendation range in panel c to control how far from your ranges to look, and turn on Always show recommendations to see near misses alongside matches. Recommended alloys aren't exported while any alloy matches.

  4. Compare with the surrogate model

    Select Show surrogate curves in panel c to overlay curves predicted by the surrogate model.

  5. Export the results

    Select Export selected in panel c to download the selected alloys as a CSV file. With nothing selected, it downloads all alloys.
